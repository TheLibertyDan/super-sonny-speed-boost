# Super Sonny Speed Boost

A tiny arcade racing game built with my 4-year-old son Sonny — a red Hot Wheels
"Rodger Dodger" muscle car racing down an orange track, dodging enemy cars,
blasting stormtroopers, dueling Darth Vader and his Inquisitors, and calling in
Captain Rex, Commander Cody, and Kix the medic as wingmen.

**Play it live:** _(add Vercel URL after first deploy)_

## Controls

**Desktop:** ← → to steer, SPACE to shoot, ESC to pause.
**Mobile:** swipe left/right to steer, tap with a second finger to shoot, tap
the pause icon top-right to pause.

## Tech

Single static `index.html`. Vanilla JS + Canvas 2D + Web Audio. No build step,
no dependencies. Just open the file in a browser.
